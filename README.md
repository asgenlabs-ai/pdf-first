# PDF First Privacy Policy Website

Static GitHub Pages website for the PDF First Privacy Policy.

## Deploy on GitHub Pages
1. Create a public GitHub repository (for example `pdf-first-privacy`).
2. Upload **all files and the `assets` folder** from this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site.
7. Use the published root URL as the Privacy Policy URL in Google Play Console.

## Important before production
- Replace the Contact section with your official support email if you want a direct email shown on the page.
- Keep the policy updated whenever app permissions, SDKs, advertising, backup behavior, or data practices change.
